# 千千梨梨桌宠

千千猫猫和梨梨兔兔的 Windows 桌宠（Electron）。

- 两只宠物站在屏幕底部，平时待机，会随机左右走动
- 鼠标左键拖动宠物；点一下会随机做一个动作
- 一分钟没人理会睡觉，鼠标靠近就醒
- 两只靠得很近会一起「贴贴」
- 右键宠物：选择显示哪只（会记住）、单独开关下面每个功能，或者退出
- 时间提醒：0 点到 5 点每 20 分钟犯困并冒气泡「该睡觉啦」；12 点、18 点左右冒气泡「该吃饭啦」
- 久坐提醒：连续用电脑 60 分钟，蹦蹦跳跳提醒「起来活动一下吧」（离开电脑 5 分钟就重新计时）
- 鼠标互动：鼠标靠近会转头看鼠标；在宠物身上快速左右晃鼠标会害羞
- 看你在做什么：用 VS Code 打字时一起敲代码；看 bilibili / YouTube 时一起看视频；网易云音乐或 Spotify 在前台时跳舞
- 掉落：把宠物拖到半空松手，它会带着重力掉下来（拖得越高落得越快），下落时播「掉落」，落地摔一下「摔趴趴」再回到待机
- 打字反应：连续打字 3 秒以上就陪你敲代码，停下来就回到待机
- 电脑状态：CPU 连续 15 秒很忙（超过 85%）会冒冷汗；笔记本没插电、电量低于 20% 时冒气泡「我也没电了……」并睡觉
- 站在窗口顶上：宠物走到当前窗口附近会跳到窗口顶边上左右走；窗口被移动、最小化、关闭或者换到别的窗口时，会掉回屏幕底部并「吓一跳」
- 托盘图标：右下角托盘里有小图标，右键（或左键）可以打开和宠物右键一样的菜单，「托盘图标」里可以换成 千千猫猫 / 梨梨兔兔 / 哥哥狗狗 / 梨梨哥哥 / 绿眼猫猫，会记住

## 隐私

- 前台窗口的程序名和标题只在你自己电脑上、在内存里判断成「写代码 / 看视频 / 听歌 / 其它」，不保存、不打印、不上传，宠物页面也只收到这个类别。
- 不读取键盘按了什么：「是否在打字」只是看「刚刚有输入，但鼠标没动」，用在「看我在做什么」和「打字反应」。
- CPU 占用和电量也只在本机看一眼，不保存。
- 程序不联网；唯一保存的是右键菜单里的选择（在本机的 settings.json）。
- 「站在窗口顶上」只需要知道前台窗口的位置，不读程序名和标题。
- 「看我在做什么」和「站在窗口顶上」都关掉后，就完全不再查看前台窗口。

## 在自己电脑上运行

1. 安装 [Node.js](https://nodejs.org/)（选 LTS 版本，一路下一步）。
2. 下载这个仓库：GitHub 页面上点绿色的 **Code → Download ZIP**，解压。
3. 在解压出来的文件夹里，按住 Shift 右键空白处 →「在此处打开 PowerShell 窗口」（或「在终端中打开」）。
4. 输入下面两行（每行输完按回车）：

   ```
   npm install
   npm start
   ```

   第一次 `npm install` 要下载一会儿。之后想再打开，只要 `npm start` 就行。

## 打包成 exe 发给朋友

在同一个窗口里输入：

```
npm run dist
```

完成后 `dist` 文件夹里会有 **千千梨梨桌宠-1.0.0.exe**，双击就能运行，不用安装，直接发给朋友就好。

> 这个 exe 没有数字签名，朋友第一次打开时 Windows 可能会弹「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可。

## 换素材

GIF 都在 `桌宠素材/` 里。每只宠物的文件夹要有 `待机`、`向左走`、`向右走`、`睡觉`、`向左看`、`向右看`、`敲代码`、`看视频`、`跳舞`、`吃饭`、`开心蹦蹦`、`害羞`、`掉落`、`摔趴趴`。除了 `待机`、走路、看、`睡觉`、`掉落`、`摔趴趴`、`冒冷汗` 之外的 GIF 都会被当成「点一下随机播放」的动作，新加 GIF 放进去就行。

托盘图标在 `桌宠素材/托盘图标/`，「绿眼猫猫」用的是 `李炜.ico`（以后改名成 `绿眼猫猫.ico` 也能认出来）。
