# 梨间雪桌宠

千千猫猫、梨梨兔兔、哥哥狗狗、梨梨哥哥、煤球猫猫、百变猫猫、99狐狐、沙漠狐、灰鸮g老师的桌宠（Electron，Windows / macOS）。

99狐狐是粉粉的小狐狸（给朋友用的），温柔又有点小得意；已经在用的人更新后默认先不显示，去「选择宠物」里勾上就会出来，新装的会直接显示。百变猫猫和沙漠狐也一样。

**百变猫猫**：一个宠物位置，五只小猫轮流出场——芝麻（灰色）、面包（有嘴筒的橘狸花）、核桃（黑狸花）、蛋黄酥（没有嘴筒的橘狸花）、西米（白色）。
- 每 2～4 分钟换下一只（五只都轮到之前不重复）：先播这只的「变身_出」，再播下一只的「变身_进」；偶尔中间插「抢出场」，或者新旧两只一起贴贴 / 叠叠乐一下再变回一只。
- 双击百变猫猫换一只；托盘菜单「百变猫猫（现在是……）」里能锁定某一只或恢复自动轮换，托盘图标选「百变猫猫」时会跟着现在这只换，托盘提示也写着现在是哪只。
- 五只一起玩（偶尔自己来，右键百变猫猫或托盘菜单也能点）：叠猫猫塔（搭 → 晃几下 → 有时倒）、排排坐点名、小猫火车（整列横穿屏幕）、一起睡觉（深夜或很久没人理更容易）、一起吃饭（饭点）、一起跳舞；结束后用「变身_进」变回一只。
- 性格：芝麻爱睡觉（困得快，晚上更容易轮到它），面包爱贴贴（喜欢凑到别人旁边，换猫时更容易两只一起贴贴），核桃爱捣蛋爱打闹（会突然追别人，更爱抢出场，叠猫猫塔更容易倒），蛋黄酥贪吃（饭点更容易轮到它，还会自己吃饭），西米傲娇（摸它有时会扭头说「哼」）。
- 跟别的宠物贴贴、叠叠乐用现在这只自己的文件：`桌宠素材/贴贴/百变猫猫_猫名/`，文件名照常写「百变猫猫」。

**沙漠狐**：大耳朵上挂着孔雀毛耳坠，爱漂亮、有点小臭美。空闲时偶尔玩自己的小爱好：刨坑、堆沙堡、偷听、追尾巴、晒太阳（白天晴天更容易晒太阳）。和 99狐狐 离得近时偶尔比尾巴；两只都睡着时，沙漠狐会用大尾巴给 99狐狐 当被子。

千千和 Claude（哥哥）、Codex（g老师）一起维护。g老师的第一份贡献：修好日记收藏夹，并让灰鸮跟着 Codex 开工 🦉。

- 六只宠物站在屏幕底部，平时待机，会随机左右走动；右键菜单「选择宠物」里每只都能单独勾选显示或隐藏
- 鼠标左键拖动宠物；点一下会随机做一个动作
- 一分钟没人理会睡觉，鼠标靠近就醒
- 贴贴：几只自己走着走着左右挨在一起，就一起「贴贴」（播完各自走开）
- 叠叠乐：拖着一只宠物，松手时落在另一只（或一摞）头上就叠上去，还能继续往上叠；播一会儿后散开，每只掉下来摔趴趴
- 特别剧情：哥哥狗狗和梨梨哥哥贴贴完会接着打一架，打完朝两边走开，之后要过好一阵才会再贴贴
- 两个哥哥和好：打完架各自走开冷静一阵（大约 3 分钟），再碰到时先「和好」再贴贴，然后又会打架……一直循环
- 追着玩：煤球猫猫偶尔突然冲向另一只，被追的那只也加速跑开，追一小会儿一起开心蹦蹦
- 送零食：千千猫猫叼胡萝卜送给梨梨兔兔吃，梨梨兔兔叼小鱼送给千千猫猫吃（两只都显示时）
- 天气：每 30 分钟查一次天气（默认湖南省长沙市市中心；菜单「天气地点…」里用「省 → 市 → 区县」三个下拉框选，也可以手动输入经纬度），按天气换待机动画：晴天 / 晴夜 / 多云 / 阴天 / 雾 / 毛毛雨 / 雨天 / 大雨 / 雷雨 / 下雪；不下雨不下雪时低于 10 度「降温」、高于 32 度「炎热」；查不到或没有这个动画就用普通待机。鼠标停在托盘图标上能看到地点、天气、气温和天气代码
- 过节：国庆、万圣节、圣诞、春节（除夕到初七）当天，宠物时不时播放节日动画
- 生日：在「宠物生日 / 番茄钟时间…」里设置每只的生日，当天那只时不时播放「生日」，大家一起冒「生日快乐」
- 番茄钟：托盘菜单「开始专注」（默认 25 分钟），专注时宠物安安静静地陪你专注；时间到了提醒休息，休息 5 分钟后问你要不要继续
- 拍照：菜单「拍照」把桌面上的宠物录成 3 秒背景透明的 GIF，存在「图片 / 桌宠照片」里并打开那个文件夹
- 测试一下：菜单「测试一下」里可以马上看到过节、生日、天气、追着玩、送零食、两个哥哥贴贴 / 和好的效果
- 功能展示：菜单「✨ 功能展示」按顺序把所有功能演示一遍（每一项头顶有气泡说明，右下角显示进度）。演示时临时显示需要的宠物，结束后恢复原来的宠物和位置；不改设置、不联网、不查天气、不弹提醒。按 Esc 或点菜单「停止展示」随时结束
- 怎么称呼你：「小设置」或新手引导第一页里设置（默认「千千」），提醒气泡、生日、纪念日、日记、新手引导、功能展示都这样叫你；联网时朋友看到的也是这个名字
- 狗狗修 bug：程序出错时把错误信息、时间、版本号记进本机的「错误日志.txt」（不记窗口标题、键盘这些隐私，路径里的用户名换成 ~），哥哥狗狗在的话会去修 bug。菜单里「打开错误日志」「复制最近的错误」方便发给哥哥排查。有新的错误时会冒气泡提醒（狗狗不在就换一只说），菜单里显示有几条新的；上次退出时记下的错误，下次打开也会提醒；打开或复制过日志就不再提醒
- 今日小日记：只在本机数当天的次数（摸摸 = 鼠标在宠物身上晃晃、点击、完成的番茄钟、贴贴、叠叠乐、遇到的天气、过的节日），不记具体内容。每天晚上 10 点（「小设置」里能改）由选好的宠物（默认哥哥狗狗，每只口吻不一样）写日记并弹出日记卡片，它没显示就由屏幕上的另一只代写；菜单「今天的日记」随时看，最多留 30 天
- 在一起多少天：记第一次打开的日子，第 7、30、100、200、365 天以及之后每满 365 天，大家一起庆祝「我们在一起第 N 天啦」；托盘悬停提示里也显示
- 两个眼镜交换：哥哥狗狗和g老师离得不远时，偶尔（最多两小时一次）交换眼镜戴
- 小插曲写进日记：当天发生过的接眼镜、盖被子、串门、换眼镜、被扶起来、叠叠乐、两个哥哥打架、挑衅，写日记时由写日记的宠物用自己的口吻提一句
- 收藏日记 / 存成图片：日记卡片右上角的 🔖 收藏这一天（一直留着，不受 30 天限制），「存成图片」把这一页连同写日记的宠物存成 PNG 到「图片/桌宠照片」；菜单「收藏的日记」可以翻看
- 打哈欠会传染：一只打哈欠，旁边的隔 2～4 秒也跟着打，最多传给 3 只；g老师被传染会先强撑，再缩进毛里睡着（鼠标靠近才醒）。晚上 11 点后传完，大家犯困慢慢走回小窝
- 全屏自动躲起来：有程序全屏（看视频、玩游戏、放 PPT）时宠物都藏起来，动画和计时都暂停，退出全屏再出来，位置不变
- 复制表情：右键宠物「复制这个表情」，把它正在播的 GIF 当成文件复制，粘贴到 QQ、微信里是会动的
- 四季换装：3～5 月春、6～8 月夏、9～11 月秋、12～2 月冬，平时的待机换成季节的；优先级：节日 > 特殊天气（雨、雪、雾、雷雨、炎热、降温）> 季节 > 其它天气 > 普通待机
- 小窝：默认在主屏幕左下角，可以拖动。晚上 11 点后困了的宠物自己走回小窝挤在一起睡，早上 7 点后或者被鼠标叫醒时出来；哥哥狗狗和g老师睡前先把眼镜放到门口的眼镜架上（睡觉没戴眼镜），起床再戴回去，两副都在架子上时早上有 30% 会拿错，戴好后接着换眼镜
- 联动 Claude Code：托盘「联动 Claude Code」里打开。这台电脑上的 Claude Code 干活时，陪着的宠物跟着做动作（默认哥哥狗狗，在「谁陪着干活」里可以换成任意一只；只有哥哥狗狗会举牌，别的干完直接开心蹦蹦）：开始干活（UserPromptSubmit / PreToolUse）就一直敲代码；干完一轮（Stop）举牌「测试通过」再开心蹦蹦（10 秒内的很短一轮只蹦一下）；等你批准或回复（Notification，或者弹出批准框 PermissionRequest）时停下来打招呼提醒；这一轮因为 API 出错结束（StopFailure，比如限流、额度用完）就停下来冒冷汗；会话结束（SessionEnd）、在等你（Notification，比如按 Esc 打断后）或 10 分钟没消息就回到平时；卡住了可以点「（它的名字）卡住了？让它停下来」，菜单里也能看到最近收到的几条事件（只有事件名和时间）。好几个会话同时开着时按 session_id 分开记，有一个在干活就接着敲。陪着的那只没放出来就什么都不做。**只对这台电脑上运行的 Claude Code 有效，云端会话不会触发**
- 退出：点「退出」时宠物们先道晚安（醒着的打招呼，睡着的接着睡），3 秒后慢慢变透明消失，再真正退出
- 新手引导：第一次打开时自动出现，一步一步介绍宠物、选宠物和大小、托盘、拖动、天气地点、生日、番茄钟、联网配对、自动更新；看完或跳过后不再自动弹出，菜单「📖 新手引导」可以再看
- 挑衅哥哥：千千猫猫离哥哥狗狗不远时偶尔会挑衅他（做鬼脸、略略略、就这、扭屁股、来打我呀、勾勾手指），哥哥狗狗会冒冷汗、跺脚、委屈、捂眼睛、追着打，或者走过来贴贴；梨梨兔兔也会挑衅梨梨哥哥（晃小鱼、装哭、戳戳、扔胡萝卜、耳朵拍拍、吓你一跳）。10 分钟内被挑衅超过 3 次，哥哥就直接投降。右键千千猫猫或梨梨兔兔可以马上「挑衅哥哥」
- 串门（要联网配对）：隔一段时间，你的一只宠物会从屏幕边上走出去，出现在对方屏幕上玩几分钟再回来；来串门的宠物进门会打招呼、冒气泡「XX 来串门啦」，能摸能拖，但不会留在对方那里。菜单「允许去串门的宠物」选哪几只能出门，右键「叫 XX 回家」随时叫回来；对方下线了宠物会自动回家
- 灰鸮g老师：点它扶眼镜（5 秒内连着点，一下比一下用力，第 4 下擦眼镜）；摔倒时哥哥狗狗在就等它来扶；不在的话旁边的宠物有时会帮它接住眼镜，没人接就假装没摔过再走开；鼠标停在它旁边 3 秒它会歪头看你，鼠标一动就往后蹦；平时偶尔看书，专注时也看书，专注到一半会打个瞌睡（旁边有宠物的话会凑过来围观，然后两只一起睡着，鼠标靠近才醒）；哥哥狗狗来批改作业、走开以后，它会夹上书签，下次批改作业就是夹着书签的版本；看书时别的宠物靠过来，它会抬起翅膀让那只挤进来一起看（只和一只，不参加多人贴贴和叠叠乐）
- 哥哥狗狗：有宠物摔趴趴时会走过去，两只一起播「扶起来」（扶起来、抖灰、道谢、摸摸头），然后各自慢慢走开；你连续打字超过 5 分钟、停下来 10 秒，它会举牌「测试通过」；晚上 11 点到早上 6 点千千猫猫睡着了，它会走过去给千千猫猫盖被子，然后两只一起睡，打字吵不醒，鼠标靠近才醒；g老师看书时它凑过去，就变成「批改作业」
- 这几对不贴贴也不叠叠乐：梨梨哥哥和千千猫猫、梨梨兔兔和哥哥狗狗、梨梨哥哥和煤球猫猫、梨梨哥哥和百变猫猫、梨梨哥哥和99狐狐、梨梨哥哥和沙漠狐；同一组玩过后会歇 30 秒
- 右键宠物：选择显示哪几只（会记住）、单独开关下面每个功能，或者退出
- 时间提醒：0 点到 5 点每 20 分钟犯困并冒气泡「该睡觉啦」；12 点、18 点左右冒气泡「该吃饭啦」
- 久坐提醒：连续用电脑 60 分钟，蹦蹦跳跳提醒「起来活动一下吧」（离开电脑 5 分钟就重新计时）
- 鼠标互动：发呆的宠物会转头看靠近的鼠标（只是换个眼神，不会打断走路、睡觉、动作、敲代码这些）；在宠物身上快速左右晃鼠标会害羞
- 看你在做什么：用 VS Code 打字时一起敲代码；看 bilibili / YouTube 时一起看视频；网易云音乐或 Spotify 在前台时跳舞
- 掉落：把宠物拖到半空松手，它会带着重力掉下来（拖得越高落得越快），下落时播「掉落」，落地摔一下「摔趴趴」再回到待机
- 打字反应：连续打字一小会儿（大约 1.5 秒）就陪你敲代码（在看鼠标、走路、睡觉时也会换），停下来就回到待机；单独点鼠标不算打字
- 电脑状态：CPU 连续 15 秒很忙（超过 85%）会冒冷汗；笔记本没插电、电量低于 20% 时冒气泡「我也没电了……」并睡觉
- 站在窗口顶上：宠物走到当前窗口附近会跳到窗口顶边上左右走；窗口被移动、最小化、关闭或者换到别的窗口时，会掉回屏幕底部并「摔趴趴」
- 控制面板：双击托盘图标（或菜单里「🎛 控制面板」）打开一个窗口，里面就是右键菜单的全部内容，做成开关和按钮，点了窗口不会关，功能和菜单完全一样
- 托盘图标（右下角）：左键点一下显示 / 隐藏桌宠；右键打开设置菜单（和宠物身上的右键菜单一样）：选宠物、大小（50%–200%）、各个功能开关、联网、托盘图标样式（千千猫猫 / 梨梨兔兔 / 哥哥狗狗 / 梨梨哥哥 / 煤球猫猫）、开机自动启动、自动更新、退出
- 联网：两个人填同一个配对码就能连上。摸自己的宠物，对方的宠物会开心蹦蹦并冒气泡「千千在摸你」（名字可以改）；右键「戳一下对方」，对方的宠物会打招呼；两个人都在线时宠物头顶有小爱心

## 隐私

- 前台窗口的程序名和标题只在你自己电脑上、在内存里判断成「写代码 / 看视频 / 听歌 / 其它」，不保存、不打印、不上传，宠物页面也只收到这个类别。
- 不读取键盘按了什么：「是否在打字」只是看「刚刚有输入，但鼠标没动」，用在「看我在做什么」和「打字反应」。
- CPU 占用和电量也只在本机看一眼，不保存。
- 「自动更新」会定时从 GitHub Releases 检查和下载新版本（不发送你的任何数据），可以在菜单里关掉。
- 「天气」的省市区县数据内置在程序里，选地点不用联网。选好的经纬度只存在本机设置里，只发给 Open-Meteo（免费天气服务）查天气，不会发给联网服务器，也不会发给朋友。关掉就不查。
- 不打开联网就不连中转服务器。打开联网后，只会发送「摸摸」「戳一下」「串门开始」「串门结束」这几种互动、宠物名和你设置的名字，服务器只转发给同一个配对码的另一个人，不保存；不传任何屏幕、窗口或键盘信息。
- 本机只保存右键菜单里的选择和联网设置（settings.json）、错误日志（错误日志.txt，只有错误信息、时间、版本号）和小日记（日记.json，只有次数、天气和节日名字，最多 30 天）。这些都不会上传。
- 「站在窗口顶上」只需要知道前台窗口的位置，不读程序名和标题。
- 「看我在做什么」和「站在窗口顶上」都关掉后，就完全不再查看前台窗口。

## 第一次安装

1. 打开 https://github.com/Lumi729/desk-pets/releases/latest
2. 在最下面「Assets」里点 **desk-pets-setup-版本号.exe** 下载。
3. 双击它。因为没有数字签名，Windows 可能会弹「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」。
4. 它会自己装好并打开，桌面上会有「梨间雪桌宠」的图标，不需要管理员权限。

以后就不用管啦：桌宠每次打开会检查一次新版本，之后每 3 小时检查一次，有新版本会在后台悄悄下载。下载好后宠物头上会一直挂着「有新版本啦，点我重启 ♡」，右下角也会弹一条通知，**点任意一个就一键重启更新**（右键托盘图标点「立即重启更新」也行；都不点的话，下次退出时也会自动装上）。

把第 1 步的链接发给朋友，朋友也这样装一次，以后也会自动更新。

## 改代码时在自己电脑上试（一般用不到）

1. 安装 [Node.js](https://nodejs.org/)（选 LTS 版本，一路下一步）。
2. GitHub 页面上点绿色的 **Code → Download ZIP**，解压。
3. 在解压出来的文件夹里，按住 Shift 右键空白处 →「在终端中打开」，输入 `npm install`，再输入 `npm start`。

用这种方式打开的不会自动更新。

## 多个显示器

宠物可以被拖到别的屏幕上，松手后会落到那块屏幕的底部，在那块屏幕上走来走去。
如果几块屏幕的「缩放」设置不一样（比如一块 100%、一块 150%），位置可能会有点偏，把缩放调成一样最稳。

## 屏幕好像卡住了？

有的电脑上，透明的桌宠窗口可能会让屏幕看起来卡住。可以右键托盘图标，勾上「兼容模式」，然后退出再打开桌宠试试（会多用一点 CPU）。

## 宠物不往窗口上站？

右键菜单里「站在窗口顶上」下面有一行灰色的小字，告诉你现在的情况：

- **找到了，宠物会跳上去**：等几秒，宠物会走过去跳上窗口顶边。
- **太靠屏幕顶上了（最大化了？）**：窗口上面要留出宠物的高度才站得下。把窗口「向下还原」（不要最大化、不要贴到屏幕顶上），往下拖一点。
- **现在没有能站的窗口**：点一下你想让宠物站的那个窗口，让它变成当前窗口（桌面和任务栏不算）。
- **读不到窗口位置**：程序用 Windows 自带的 PowerShell 读窗口位置，可能被安全软件拦了，把桌宠加到信任里再试。

## 联网：把中转服务部署到你的 Cloudflare 账号

服务端代码在 `server/` 文件夹里（Cloudflare Workers + Durable Objects，免费计划就够用）。

1. 注册并登录 [Cloudflare](https://dash.cloudflare.com/sign-up)。
2. 在 `server` 文件夹里打开终端（和前面一样：按住 Shift 右键空白处 →「在终端中打开」），依次输入：

   ```
   npm install
   npx wrangler login
   npm run deploy
   ```

   `wrangler login` 会打开浏览器，点「Allow」同意就行。
   第一次部署如果提示要注册 workers.dev 子域名，按提示起一个名字。
3. 部署成功后终端会显示一个地址，类似 `https://desk-pets-relay.你的名字.workers.dev`。用浏览器打开它，看到「千千梨梨桌宠的中转服务正在运行 ♡」就好了。
4. 默认服务器已经设成 `https://desk-pets-relay.fengxiaolou925.workers.dev`，大家都不用填服务器地址。以后换了地址，告诉哥哥改 `lib/online.js` 里的 `DEFAULT_SERVER` 就行。
5. 在桌宠右键菜单 →「联网」→「联网设置」里：填你的名字，点「随机生成配对码」，再点「复制」发给对方，最后点「保存并连接」。
6. 对方在联网设置里粘贴同一个配对码，保存，就连上啦。

一个配对码最多两个人。以后改了 `server/` 里的代码，再运行一次 `npm run deploy` 就会更新。

> 加「串门」时服务端也改了（多转发串门开始 / 结束），需要在 `server` 文件夹里再运行一次 `npm run deploy`，串门才能用。
>
> 部署完可以在菜单「测试一下」→「检查服务器能不能串门」看看是不是新版；「串门：假装有客人来玩」不用朋友也能看到客人进门的样子。

跟哥哥（Claude）说「**发布新版本**」就好。

哥哥会把版本号改大一点推上去。GitHub 发现版本号变了，就会自动：

## 选一只宠物跟着 Codex 开工

1. 打开托盘菜单或控制面板「联动 Codex（g老师）」→「谁陪着干活」，七只宠物都能选，默认仍是灰鸮g老师，重启后也会记住。先在「选择宠物」里把选好的那只放出来，再打开「让它跟着 g老师开工」的开关。
2. 第一次需要在 Codex 里审核并信任「灰鸮桌宠联动」hooks。支持 hooks 的 Codex 命令行可输入 `/hooks` 查看并审核。之后新开本机聊天；如果没有这个入口，需要先更新 Codex。详见 [Codex 官方 hooks 说明](https://learn.chatgpt.com/docs/hooks)。
3. g老师开工时选好的宠物持续敲键盘；等你批准或回答问题时灰鸮扶眼镜、其他宠物打招呼，并冒气泡；收工后蹦一下；手动中断则安静停下。几场聊天同时开着，有一场还在忙就继续敲。宠物在摔倒、贴贴、剧情或小窝里时先做完原来的事。工作途中换宠物会交接；Codex 和 Claude Code 可以各选一只，也能选同一只，同一只会等双方都收工才停。

还没接上时，菜单会显示「等待 Codex 发来第一个状态」，不会把“开关开了”当作“联动成功”。「最近收到的」可看事件时间；「测试一下」→「所选宠物：联动 Codex」能预览三个动作，测试动作不代表真的接上了。长时间没事件（10 分钟）会自动停下，也可以点「所选宠物卡住了？让它停下来」。

只适用于在这台 Windows 电脑运行、支持并启用了 hooks 的 Codex 本地聊天；普通 ChatGPT 网页、云端任务不触发。Codex 没有在这里使用的 API 出错事件：异常结束若未发中断或收工消息，需等超时或手动让灰鸮停下。

输入统一按 UTF-8 读取，中文回复、引号、换行和表情不会受 Windows 控制台的旧编码影响。收工消息里附带的回答只在内存中解析后丢弃，不记录、不转发。

联动会先备份 `%USERPROFILE%\.codex\hooks.json`（设置了 `CODEX_HOME` 时用对应目录），只增删属于桌宠的命令，保留其他 hooks。命令在 `lib/codex-hooks.js` 中；用 PowerShell 从输入里取出会话、轮次、时间和是否等回应，**不转发提示词、工具参数、回答、文件路径**，只发到 `127.0.0.1:47292`。桌宠接收开工、工具前后、审批、收工、中断、会话结束七种事件，回复空内容；没开桌宠也静默退出。本机请求直接使用 .NET HTTP 接口，每次网络等待限 800 毫秒；普通事件留 10 秒供进程冷启动，中断和会话结束遵守 Codex 的 3 秒上限。不改 Codex 的审批、权限或信任决定；升级旧命令时也会提醒你重新审核，不能沿用旧命令的信任。

## 联动 Claude Code 是怎么做的

- 打开开关时，先把 `%USERPROFILE%\.claude\settings.json` 备份成 `settings.json.desk-pets-backup-时间`，再往里面**加**我们的 hooks（UserPromptSubmit、PreToolUse、PostToolUse、Stop、StopFailure、Notification、PermissionRequest、SessionEnd；PermissionRequest 只是看一眼，没有任何输出，不会替你允许或拒绝），已有的 hooks（比如 Clawd on Desk 加的）一条都不动；关掉时只删我们加的那几条。
- 每条 hook 是一行在 Git Bash 和 PowerShell 里都能跑的命令：用 `curl.exe` 把 hook 收到的 JSON 转发到 `http://127.0.0.1:47291/desk-pets-claude/事件名`。`-s -o NUL` 保证没有任何输出（UserPromptSubmit 的输出会进 Claude 的上下文），连不上 1 秒就放弃、最多 2 秒，最后 `exit 0`，所以桌宠没开时不会报错，也不会拖慢 Claude Code。
- 桌宠只在 `127.0.0.1`（只有本机能连）开这个小接口，收到就回 204 空内容，只看事件名和 session_id，不联网、不往外发任何数据。
- 改完 hooks 后，新开的 Claude Code 会话才会生效。

## 数据来源

天气地点用的全国省、市、区县数据（`lib/regions.json`）由 `scripts/build-regions.js` 从下面两份公开数据生成，都是 MIT 许可证，许可证原文在 `lib/regions-LICENSES.txt`：

- 省市区县名单：[cn-division](https://github.com/kk-418/cn-division) 2026.0.1（民政部地名服务 2026 年行政区划数据），MIT
- 区县中心点经纬度：[cpca](https://github.com/DQinYuan/chinese_province_city_area_mapper) 0.5.5 的 `resources/adcodes.csv`，MIT

cpca 的经纬度比名单旧一些：后来改名的区县（比如宁乡县 → 宁乡市）用改名前的位置；少数新设的区县（比如深圳龙华区、杭州钱塘区）没有自己的位置，用所在城市的中心点。需要更准的话可以在「天气地点」里手动输入经纬度。

## macOS 测试版

支持 Apple 芯片（arm64）和 Intel（x64），分别生成 `desk-pets-版本-mac-arm64.dmg` 和 `desk-pets-版本-mac-x64.dmg`。在 Mac 上打开 DMG，把应用拖到「应用程序」，再从那里启动；不要长期从磁盘映像里运行，工作联动会记住应用位置。

当前尚无 Apple Developer ID 签名和公证，属于测试版；首次打开可能被系统拦截。仅在确认下载来源后，按 macOS「系统设置 → 隐私与安全性」中的提示允许打开，不需要关闭系统安全保护。菜单里的「打开新版下载页」用于手动下载安装；Mac 暂不自动安装更新，Windows 自动更新不受影响。

菜单栏的小宠物图标可打开菜单，选择「打开控制面板」或「显示 / 隐藏桌宠」。基础动画、拖动、贴贴、日记、天气、番茄钟、串门和本机 Codex / Claude Code 联动保留。Codex 首次仍须由用户审核 hooks；Mac 命令使用应用自带运行环境，不要求额外安装 PowerShell 或 Node。移动应用后关闭再开启联动，Codex 命令变化后重新审核。

1.0.31 的限制：仅主屏与 Windows 窗口识别；后续开发测试构建的多屏与窗口互动见下节。Mac 不覆盖全屏应用的独立空间。「复制这个表情」在 Mac 上也是把 GIF 当成文件复制（用系统自带的 osascript），复制不了时改为在 Finder 里显示，拖进聊天即可。

开发与检查：Mac 上运行 `npm ci`、`npm test`、`npm start`；`npm run dist:mac` 构建两种芯片的 DMG。每次相关代码推送后，Actions 会在 Mac 上测试、启动真实桌宠窗口并保留两种 DMG 为 `mac-installers` 测试附件（14 天）。版本号未变时不会修改现有公开版本；下次正式发布时，须等 Mac 安装包和 Windows 安装包都齐全再公开。自动启动检查不代替实机验证：仍需检查 Retina 显示、拖动与鼠标穿透、Spaces 切换、登录启动、菜单栏、联动开工与收工，以及另一种芯片的真实运行。

## Mac 窗口互动与多屏（开发测试版）

新版测试构建已接入原生窗口读取：在菜单「Mac 窗口互动」点击「允许窗口互动」，由你在系统「隐私与安全性 → 辅助功能」确认允许。再到「功能开关」打开「看我在做什么」「站在窗口顶上」「有程序全屏时自动躲起来」。升级前关闭的开关不会擅自打开。授权后可点「重新检查窗口」；某些应用不提供窗口信息时宠物继续在桌面活动。组件只读取前台窗口位置与全屏状态；只有活动分类开启时才读取标题，标题只在本机内存中分类，不截图、不读取按键、不保存或上传标题。

多屏改为每块显示器一个透明显示窗口，共用唯一宠物状态。宠物、贴贴、日记与联动不会按屏幕复制；按住宠物可跨屏拖动，松手落到目标屏幕。菜单「测试一下 → 把宠物分到不同屏幕」可立即检查各屏幕是否显示。「功能展示」也有窗口与多屏介绍。不同缩放比例、上下/左右排列、全屏 Spaces 和真实跨屏鼠标捕获仍需实机试用。

Mac 开发者先运行 `npm run build:mac-helper`（需要 Xcode 命令行工具），再 `npm start`；安装包已经带有通用架构的窗口组件，普通用户不需要编译或安装开发工具。辅助功能授权不可由程序自动开启，未授权/撤销权限会清掉旧窗口状态并在菜单提示。

正式苹果签名、公证与自动下载安装更新仍待 Apple Developer 账号配合，测试版继续手动下载更新。
