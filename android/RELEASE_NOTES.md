# 梨间雪桌宠 · Android 0.17-preview

2026-10-08 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.15-preview 基础上）。

- 住在屏幕边：设置「住在地面 / 住在屏幕边」给每只伙伴选住哪里，默认住在地面。住在边上的贴着左边或右边探头，只露出头和爪子。
- 它会时不时沿着边爬上爬下换高度，偶尔掉下来换到另一边；不挡状态栏、灵动岛和底部导航条，键盘弹出时避开。
- 摸它会缩回去再探出来；拖着放到边上能换高度，拖回地面就变回住在地面。
- 不参加贴贴和叠叠乐；灵动岛来通知时照样去挂着，挂完回原来的边上。
- 测试菜单新增「住到左边」「住到右边」，功能展示也加上。

可以在设置页「更新」里检查更新、直接覆盖安装，设置会保留。电脑版版本不变。
