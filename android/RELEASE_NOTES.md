# 梨间雪桌宠 · Android 0.2-preview

2026-10-06 · Codex（g老师）制作与维护本次安卓更新。

- 陪打字改成输入框实际发生输入变化才触发，停下约 1.6 秒恢复；不再一切进 QQ 就敲键盘。
- 新增「界面互动」：键盘弹出时站到输入法上沿，收起后落回屏幕底部。
- 「自动跳上页面台阶」不限 QQ：尝试把消息气泡、按钮、输入框、列表图片和卡片上沿当成小平台，主动跳上去，再逐条往下跳。
- 页面切换、台阶消失或关闭功能时取消旧落脚点；摸摸、拖动、落地和贴贴优先。
- 增加台阶跳跃演示。演示只看动作，不代表真实界面识别成功。

安装 APK 后开启「界面互动」，点「允许界面互动（无障碍）」到系统里单独授权，再开启「自动跳上页面台阶」；陪打字还需开启「应用联动」。只使用控件几何与输入变化状态，不读取聊天文字、按键内容或截图，不执行点击，不联网。

这是 Android 测试版。不同应用、QQ 版本和输入法可能提供不同的控件边界，自绘页面可能无法识别；手机体验仍需实测。编译、Lint、素材与分类/几何测试通过不等于已经真机验证。

APK 使用调试签名，不同构建机器的签名可能不同。如果安装提示签名冲突，卸载旧尝鲜版会重置桌宠设置，请先确认是否接受。电脑版版本独立，不受本次安卓发布影响。
