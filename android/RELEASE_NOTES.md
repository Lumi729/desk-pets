# 梨间雪桌宠 · Android 0.6-preview

2026-10-07 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.4-preview 基础上）。

- 挂在灵动岛下面：打开「伙伴挂在提示条下面」后，提示条一出现就挂上去，充电、计时、音乐、通知都算；提示条消失后落回地面。拖动它会先不挂，等提示条下次出现再挂。
- 点提示条打开通知：提示条上显示外卖或你选中应用的消息时，点一下直接打开那条消息；长按提示条打开音乐控制和计时器面板。
- 通知图标：通知栏小图标换成新的单色剪影，下拉通知里是粉色，右边显示彩色千千猫猫。

新功能默认关闭，按需开启。0.5-preview 起可以在设置页「更新」里检查更新、下载并安装；沿用固定签名，可以直接覆盖安装，设置会保留。挂的位置和不同手机的效果仍需真机验证。电脑版版本不变。
