# 梨间雪桌宠 · Android 0.22-preview

2026-10-08 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.15-preview 基础上）。

- 新的灵动面板（长按灵动岛打开）：照千千的设计稿换成像素风，边角是像素台阶，图标是 11×11 像素格放大。
- 「正在播放」卡片显示歌名、像素进度条和上一首 / 播放暂停 / 下一首；没在放歌时写「没有在放歌」，按钮变灰。
- 下面三行：取消计时器（有计时才显示剩余时间）、隐藏提示 30 秒、位置大小与拖动。千千猫猫坐在面板顶边陪着。
- 点面板外面或关闭收起；功能和原来一样。

可以在设置页「更新」里检查更新、直接覆盖安装，设置会保留。电脑版版本不变。
