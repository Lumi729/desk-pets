# 梨间雪桌宠 · Android 0.24-preview

2026-10-09 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.15-preview 基础上）。

- 美化主题：内置千千猫猫（默认，深色）和梨梨兔兔（浅色）。一个主题同时换灵动岛、灵动面板和设置页的颜色与像素图，面板顶上坐着主题的伙伴。
- 设置页「美化主题」卡片：下拉框选主题马上生效，旁边有灵动岛小样；可以导入美化包（.zip，按格式说明严格检查，不对会用一句话说原因）、导出当前主题、删除导入的主题。
- 设置页重新排版：顶部是标题、权限提示和「让桌宠出来玩」；其余收进伙伴、陪你用手机、灵动岛、天气与日常、美化主题、权限、测试与更新 7 张可折叠卡片。授权都集中在「权限」卡片，长说明点「ⓘ」才显示。原来的设置一个都没少。
- 测试菜单新增「切换美化预览」，功能展示也加上。

可以在设置页「测试与更新」里检查更新、直接覆盖安装，设置会保留。电脑版版本不变。
