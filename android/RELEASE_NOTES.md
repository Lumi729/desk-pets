# 梨间雪桌宠 · Android 0.7-preview

2026-10-07 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.4-preview 基础上）。

- 天气与季节换装：和电脑版一样，下雨、下雪、起雾、打雷、很热、降温时换成对应的待机；平时按春夏秋冬换装；晴天晚上是晴夜。只换平时站着的样子，不打断摸摸、拖动、贴贴和陪打字。
- 天气地点：在设置里选 省 → 市 → 区县，默认湖南省长沙市市中心。不需要定位权限，只把所选地点的经纬度发给天气服务 open-meteo；桌宠开着时最多半小时查一次，查不到就用普通待机。
- 设置页显示当前地点、天气、气温和季节。
- 测试菜单新增「天气演示」，所有天气和四季轮流播一遍；功能展示最后也会演示。
- 下拉通知右侧换成千千猫猫的像素大图标。

新功能默认关闭，按需开启。可以在设置页「更新」里检查更新、直接覆盖安装，设置会保留。电脑版版本不变。
