# 梨间雪桌宠 · Android 0.4-preview

2026-10-06 · Codex（g老师）制作与维护本次安卓更新。

- 修复窄台阶上不停左右闪动：站稳等待跳走。
- 掉落时落到脚下可识别的下一层台阶，不再直接穿过所有台阶到底。
- 可选重力与摇晃互动：连续摇晃后像弹力球飞动，倾斜改变方向，结束出现彩虹效果。
- 顶部灵动提示条：陪伴状态、音乐标题与上一首/播放暂停/下一首、选定应用通知标题、外卖取餐通知提示、充电电量、本地计时。
- 点击提示条打开控制面板；测试菜单可演示窄台阶、摇晃和提示效果。

新功能默认关闭，按需开启。音乐与通知功能需单独授予通知访问权限；只有你选中的应用才显示通知标题，外卖开关仅匹配美团、美团外卖与饿了么的取餐通知。信息不保存、不上传，通知提示不等于查询真实订单状态。计时只在桌宠服务运行时检查，系统清理服务后不能保证提醒；本版没有电话接听等系统级灵动岛功能。

页面台阶需要开启界面互动并授予无障碍权限，只使用控件几何，不读取聊天文字或截图。不同应用的台阶、音乐控制和通知支持存在差异，仍需真机验证。

沿用 0.3-preview 的固定签名，可尝试直接覆盖安装；0.1/0.2 旧调试签名若冲突，迁移需卸载旧版（会清除设置）。电脑版版本不变。
