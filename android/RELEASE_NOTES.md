# 梨间雪桌宠 · Android 0.16-preview

2026-10-08 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.15-preview 基础上）。

- 歪手机爬墙：在设置里打开「歪手机爬墙」后，手机往左或往右歪一会儿，离那边最近的伙伴走过去，沿屏幕边爬到上半部分，藏在边外只露出头和爪子。
- 不管它就一直趴着；点它、摇手机、长按都不会下来，只有拖出来才掉回地面。爬过一只要先把手机摆正才会再爬下一只。
- 同一时间最多一只去爬；贴贴、剧情、叠叠乐、挂灵动岛时不爬。默认关闭。
- 测试菜单新增「爬左边」「爬右边」，功能展示也加上。

可以在设置页「更新」里检查更新、直接覆盖安装，设置会保留。电脑版版本不变。
