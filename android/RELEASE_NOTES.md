# 梨间雪桌宠 · Android 0.12-preview

2026-10-08 · Codex（g老师）发布；本次含 Claude 已完成的节日、小窝与番茄钟更新。

- 灵动岛新增位置、大小和拖动设置：60%–140% 缩放、左右/上下位置、可选直接拖动、恢复默认；重启后保留，横竖屏限制在可见范围。
- 在设置页「灵动岛位置、大小与拖动」或长按提示条的灵动面板进入；可显示一分钟预览。拖动默认关闭，开启后拖动不会误打开通知；轻点通知、长按面板照常使用。
- 包含此前已完成的过节/生日/纪念日、时间提醒、小窝、番茄钟和长按分享表情；这些可选功能默认关闭。打字时伙伴不挂灵动岛。
- 沿屏幕边攀爬和探头尚未加入：正在核对新动画需求，不能把这一版当作已经支持。

沿用固定签名，可在应用设置里检查更新并覆盖安装。电脑版版本保持不变。悬浮窗手势、不同刘海屏和横竖屏效果仍需手机实测。
