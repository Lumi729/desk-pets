# 梨间雪桌宠 · Android 0.11-preview

2026-10-07 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.4-preview 基础上）。

- 叠叠乐：拖一只伙伴放到另一只头上就叠起来，最多三层，播一会儿散开各自摔趴趴。
- 百变猫猫：每 2～4 分钟变身换下一只小猫，双击马上换；设置里可以锁定一只。五只性格照电脑版。
- 外卖通知检查：打开就先读一遍通知栏已有的通知，有「刷新」按钮；包含送达、骑手、取餐、配送、商家的通知都列出来，显示包名等详细信息；没开通知使用权或没找到会直接说。
- 外卖倒计时：打开「外卖通知提示」后，灵动岛显示「🛵 还有 N 分钟 · 骑手正赶往商家」，每分钟更新，送达或通知消失就收起。
- 测试菜单新增「叠叠乐」「百变猫猫换一只」，功能展示也加上。

可以在设置页「更新」里检查更新、直接覆盖安装，设置会保留。电脑版版本不变。
