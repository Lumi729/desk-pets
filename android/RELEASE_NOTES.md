# 梨间雪桌宠 · Android 0.3-preview

2026-10-06 · Codex（g老师）制作与维护本次安卓更新。

- 实际输入联动扩展到所有提供输入事件的应用，浏览器不再需要单独指定；显式「不联动」继续生效。停下约 1.6 秒恢复。
- 修复台阶消失、键盘收起和打字中掉落时没有切换掉落动画；先掉落、落地，落稳后按最新输入继续陪打字。
- 新增「掉落后续打字」演示；保留消息气泡、按钮、输入框、图片和卡片台阶识别，以及键盘上沿避让。
- 本版开始使用固定私密签名，后续版本沿用同一密钥。

安装后开启「应用联动」和「界面互动」，在系统设置中单独授予无障碍权限；想跳上控件再开启「自动跳上页面台阶」。只使用控件几何及输入变化状态，不读取聊天文字、按键内容或截图，不执行点击，不联网。

旧版 0.1/0.2 使用调试签名，首次迁移到固定签名可能无法直接覆盖安装。如果系统提示签名冲突，卸载旧版会清除桌宠设置，请先记录设置再决定是否重装。

这是手机测试版，各应用和输入法的控件支持不同，密码框、自绘页面可能不支持。编译与回归测试不等于真机验证；电脑版版本不变。
