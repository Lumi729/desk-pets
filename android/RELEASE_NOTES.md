# 梨间雪桌宠 · Android 0.27-preview

2026-10-10 · Claude 修复与发布（在 Codex（g老师）的 0.26-preview 基础上）。

- 导入美化包时，宽或高超过 512 像素的图片直接拒绝并说明原因；以前这种图压缩后很小，但每次打开都会闪退。
- 外卖提示：「骑手已到达商家，等待出餐」这类到店取货的通知，不再误报成「骑手提醒你取餐」。
- 滚动歌词只在音乐 App 放歌、而且有真正的歌名时才去查；B站视频和「媒体播放」这种占位标题不再拿去搜歌词。
- 伙伴没出来时点「收起 / 继续」「结束专注」，不会再先把伙伴放出来再收起。
- 素材读不出来时，不会再因为没进前台就被停掉而崩溃。
- 导入美化时，云盘或文件管理器给的文件地址失效，设置页不再崩，会提示「读不了这个文件」。
- 选中的美化包坏了或丢了，会自动换回千千猫猫，不再每一帧都重新读一遍。
- 歌词换句的动画结束后，换主题时灵动岛的文字颜色会跟着变，不会白底白字。

可以在设置页「测试与更新」里检查更新、直接覆盖安装，设置会保留。电脑版版本不变。
