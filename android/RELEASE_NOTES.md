# 梨间雪桌宠 · Android 0.5-preview

2026-10-07 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.4-preview 基础上）。

- 摇一摇：宠物像弹力球飞的时候播新的「摇晃」动画，落地后吐出一道彩虹（彩虹画在动画里），再回到待机。
- 像素灵动岛：顶部提示条换成像素风胶囊，两头不拉伸、中间拉长，放大后依然清晰。
- 挂在灵动岛下面：打开「通知时伙伴挂在提示条下面」后，外卖提示或你选中的应用通知出现时，选好的伙伴（默认第一只出来的）跑过去跳上去挂着；提示条消失后落回地面。
- 测试菜单新增「吐彩虹」「挂灵动岛」和「功能展示：摇晃 → 吐彩虹 → 挂灵动岛」。
- 检查更新：设置页「更新」里可以手动检查，也可以打开「自动检查更新」（最多 12 小时一次）。有新版本会先问你，下载好后打开系统安装界面，由你点「安装」；第一次需要允许「安装未知应用」。只连接 GitHub 上桌宠的发布页，这是应用唯一联网的地方。
- 没画「摸摸头」的伙伴点一下改播「害羞」，不再停在待机；应用图标换成千千猫猫。

新功能默认关闭，按需开启。挂的位置、不同手机的状态栏高度、下载安装流程都还需要真机验证。

沿用固定签名，可以直接覆盖安装 0.3 / 0.4-preview，设置会保留。从这一版开始，以后的新版本可以在应用里检查和下载。电脑版版本不变。
