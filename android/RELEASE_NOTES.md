# 梨间雪桌宠 · Android 0.9-preview

2026-10-07 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.4-preview 基础上）。

- 挑衅哥哥：千千猫猫偶尔挑衅哥哥狗狗，梨梨兔兔偶尔挑衅梨梨哥哥，哥哥们会冒冷汗、跺脚、委屈、追着打或者贴贴；10 分钟里被挑衅超过 3 次就投降。长按千千猫猫或梨梨兔兔也能叫它去挑衅。
- 两个哥哥：哥哥狗狗和梨梨哥哥贴贴完会打一架，冷静大约 3 分钟后再见面先和好再贴贴。
- 听音乐、看视频时伙伴不挂灵动岛，照常陪你看视频、跳舞；通知、充电、计时还是会挂。
- 测试菜单新增「挑衅哥哥」「两个哥哥打架和好」，功能展示也加上。

拖动、摸摸随时能打断剧情。可以在设置页「更新」里检查更新、直接覆盖安装，设置会保留。电脑版版本不变。
