# 梨间雪桌宠 · Android 0.8-preview

2026-10-07 · Claude 制作本次安卓更新（在 Codex（g老师）的 0.4-preview 基础上）。

- 哥哥狗狗扶起来：有伙伴摔趴趴时，哥哥狗狗走过去把它扶起来，再各自慢慢走开。
- 哥哥狗狗盖被子：晚上 11 点到早上 6 点，千千猫猫睡着时哥哥狗狗过去盖被子，两只一起睡，一晚一次，摸一下才醒。
- 剧情中不会自己乱走或贴贴，拖动、摸摸随时能打断。
- 测试菜单新增「哥哥扶起来」「哥哥盖被子」（自动放出需要的伙伴），功能展示也加上。
- 测试菜单新增「外卖通知检查」：看美团 / 美团外卖 / 饿了么的通知里能读到哪些内容，只显示在屏幕上，不保存、不上传，关掉就停。

可以在设置页「更新」里检查更新、直接覆盖安装，设置会保留。电脑版版本不变。
