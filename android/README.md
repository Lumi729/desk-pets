# 梨间雪 · 安卓尝鲜版 0.5-preview

安装包：[Android 0.5-preview 发布页](https://github.com/Lumi729/desk-pets/releases/tag/android-v0.5-preview)。本次更新署名：Claude，2026-10-07（0.4-preview 由 Codex（g老师）制作）。

原生 Android 悬浮桌宠，Android 8.0 及以上。安装 APK 后打开「梨间雪桌宠」，选择伙伴，点「让桌宠出来玩」，按照手机提示允许「显示在其他应用上层」，返回应用即可开启。通知权限用于显示收起和关闭按钮。

## 应用联动与双击跳跃

打开「应用联动」，点「允许识别当前应用」，在系统页允许使用情况访问权限，回到桌宠启动后切换应用。约两秒后视频、音乐应用分别切到看视频、跳舞；所有提供输入事件的应用仅在「界面互动」检测到实际输入变化后敲代码，停下约 1.6 秒恢复；摸摸、拖动、落地和贴贴优先播放，再恢复联动。双击宠物会向上跳起再落地。

「设置每个应用的动作」可给手机上能启动的应用自定义动作，也可以单独不联动。酒馆使用的浏览器无需单独指定：可识别的实际输入变化会触发陪打字，显式「不联动」的应用除外。视频/音乐判断的是当前应用，不是播放状态。打字联动需另外启用界面互动，不会因打开 QQ 或浏览器就开始敲键盘。不读取网页地址、文字、按键内容或画面。切到未分类应用恢复散步，关闭开关、收起或熄屏时停止查询。只有用户配置会保存，识别到的应用不保存、不上传。多窗口场景以最近恢复的应用为准，未收到事件时不会猜测。

「测试动作 / 功能展示」可以立即播放三种动作、跳跃及「气泡台阶跳跃演示」。演示使用临时台阶，仅展示动作，不代表识别到了实际气泡。

## 界面互动（手机测试）

打开「界面互动 · 输入与键盘避让」，点「允许界面互动（无障碍）」，在系统设置中单独开启「界面互动 · 梨间雪桌宠」，返回后启动桌宠。应用不会自行授权，悬浮窗、使用情况访问、通知和无障碍权限分别由系统管理。

- 键盘弹出时使用输入法窗口顶边作为地面，宠物在键盘上方，收起键盘后落回屏幕底部。悬浮窗不获取输入焦点。
- 「应用联动」开启且未被设为「不联动」的应用中，只在聚焦的非密码输入控件发生输入变化时播放敲代码；不会取出事件文字或按键内容。程序修改聚焦输入框也可能产生同类事件，无法区分所有输入来源。
- 另外打开「自动跳上页面台阶（测试）」，不限应用：把可识别的按钮、输入框、滚动列表中的消息/文字内容、列表图片与卡片上沿作为台阶，自动从较高台阶逐条向下跳。紧贴的内容容器优先作为气泡边界；排除过小的头像、居中时间标签和整页容器，但不同应用仍可能误选。只使用控件类型、资源 ID、可见性与边界，不读取文字或描述、不执行点击或手势。
- 切换应用、滚动导致台阶消失、键盘位置变化或关闭功能时取消旧落脚点；摸摸、拖动、落地、贴贴仍优先于自动跳跃。关闭散步也会暂停自动跳台阶。
- 没提供可用边界的应用版本或自绘页面不会猜测台阶，宠物继续散步。当前规则是测试识别，需要手机检查是否误选文字标签、是否对齐目标；编译成功不代表已经在各应用真机验证。

观察只在界面互动开关开启、桌宠可见、屏幕解锁时运行，收起/熄屏/关闭后清空状态，不保存或上传界面信息。无障碍服务由用户在系统设置中开启或撤销。

## 这一版可以做什么

- 最多三只一起出场，选择保存在手机上；百变猫猫五种花色先手动选择。
- 待机、自动散步、点一下摸摸、拖动放手后掉落和摔趴趴。
- 两只靠近后贴贴，沿用电脑版的禁配规则和专属素材；选好后点「试试贴贴」也能马上播放。
- 长按宠物打开设置；调整大小；关闭散步；通知栏「收起 / 继续」「全部回家」。
- 每只使用一个小悬浮窗，不用全屏透明层，宠物方框外的区域正常操作。熄屏暂停绘制与移动，横竖屏切换时回到可见范围。

这是独立的手机端起步版本：暂未加入电脑版的小窝、日记、联网、天气、多人叠叠乐、百变自动轮换与 AI 工作联动。没有联网权限，界面互动可选地观察其它应用控件位置与输入变化，不读取聊天文字，不会随开机自动启动。被系统清理后需要再次打开；不同品牌若限制后台运行，可在应用的电池设置中允许后台运行。系统安全页面也可能主动隐藏悬浮窗。

## 构建

需要 JDK 17、Node.js、Android SDK 35 和 Gradle 8.13：

```sh
cd android
gradle :app:assembleDebug :app:lintDebug
```

安装包在 `app/build/outputs/apk/debug/app-debug.apk`。构建前自动从仓库的桌宠素材抽取需要的 GIF，无需复制素材或装 npm 依赖。`node --test test/android-assets.test.js` 在仓库根目录检查所有素材和配对规则。

`Android 测试安装包` GitHub Actions 运行仓库测试、分类/几何 Java 测试、编译和 Android Lint，保留 APK 附件。安卓版本号变化时发布独立 `android-v<版本号>` 预发布与 APK；版本号不变保留已有发布。不会触发电脑版发布或改变电脑版 latest。发布说明在 `android/RELEASE_NOTES.md`，署名与日志要同步更新。Debug APK 仅用于尝鲜：不同构建机器的默认调试签名不同，覆盖安装遇到签名冲突需卸载旧尝鲜版（设置会重置）。正式长期分发前须配置保管好的固定签名。

## 固定签名配置（已设置）

从此发布流程只接受固定签名的 release APK，不再把随机调试签名作为新版公开发布。旧版 0.2-preview 保留，0.3-preview 起使用固定签名，缺少密钥时发布会明确失败。

仓库 Actions secrets 需要 `ANDROID_KEYSTORE_BASE64`（PKCS12 密钥文件的 base64）与 `ANDROID_KEYSTORE_PASSWORD`；密钥别名为 `deskpets`，密钥密码与文件密码相同。私钥不能提交到源码、Actions 附件或日志；应保留私密备份。配置后每个版本使用同一密钥。

旧版调试密钥未保留在仓库；如果无法找回已安装 APK 对应的私钥，固定签名不能直接覆盖旧签名，迁移可能仍需最后一次重装。不能从 APK 的公开证书还原私钥。

### 0.3-preview：输入与掉落修复

开启应用联动与界面互动后，所有提供输入事件的应用都可尝试陪打字，浏览器无需单独选择。密码框与自绘控件可能不支持；显式“不联动”继续生效。失去台阶先播放掉落、落地，落稳后按最新输入继续打字。测试菜单可演示这一顺序。固定签名已配置，本版起复用；备份由仓库所有者私下保管。

## 0.4-preview：逐层掉落、摇晃和灵动提示

窄台阶容不下散步时站稳等候，不逐帧反向；更宽的平台只在走到前进方向的边界时掉头。测试菜单新增窄台阶演示。

默认关闭的「重力与摇晃互动」使用加速度传感器：轻轻连续晃动后短暂弹力球运动（播「摇晃」），倾斜可改变飞行方向，落地后播一遍「吐彩虹」再回待机。触摸拖动可以打断；收起或熄屏会注销传感器。设备没有加速度计时可使用演示按钮。

「顶部灵动提示条」在打字/视频/音乐联动时显示提示，点击可打开控制面板。「外卖通知提示」需独立授予通知访问权限；只在开关开启时临时读取美团、美团外卖、饿了么通知标题和正文，保守匹配取餐提示，不扫描通知历史、不保存正文、不上传、不执行通知操作，不读取其他应用正文。普通推广和预计到达通知不提示；不保证识别所有模板，也不等于查询订单实际状态。系统可能限制通知访问或隐藏通知内容。授权系统权限不等于默认开启上述功能。

掉落时检查脚下可识别的平台，优先落在最近的下一层；起跳平台不会把宠物重新接住。音乐开关可显示当前媒体标题并提供上一首、播放/暂停、下一首（取决于播放器支持）；可单独选择允许显示通知标题的应用。充电时可显示电量，计时提供 1/5/15/25 分钟选项，只在桌宠服务运行时检查，不能替代系统闹钟。点击提示条打开控制面板。新增功能仍需真机验证，本版未接入电话接听等系统级功能。

### 像素灵动岛和挂在提示条下（Claude，2026-10-06）

提示条背景换成 `桌宠素材/灵动岛/` 的左、中、右三张像素图拼成的胶囊：左右两段不拉伸，中间那段横向平铺，按整像素最近邻放大保持清晰，文字放在中间段。

新开关「通知时伙伴挂在提示条下面」默认关闭。打开后，外卖提示、选中应用的通知出现在提示条上时，一只伙伴会先跑到提示条正下方，再跳上去挂着播「灵动岛」（GIF 最上面一行的爪子 / 耳朵压住提示条底边一点）；提示条消失后用原来的掉落动作落回地面。挂哪只可以在「选择挂在提示条下的伙伴」里选，默认第一只出来的；选的那只没出来就换成第一只。拖动或双击它会取消这一次。

测试菜单新增「吐彩虹」「挂灵动岛」（演示不看开关）和「功能展示：摇晃 → 吐彩虹 → 挂灵动岛」。挂的位置、窗口层级和不同手机的状态栏高度仍需真机验证。

### 检查更新和自动更新（Claude，2026-10-06）

设置页「更新」里有「检查更新」按钮和默认关闭的「自动检查更新」（最多 12 小时一次，打开设置页或让桌宠出来时检查，有新版本会发通知）。只读取本仓库 GitHub Releases 里 `android-v` 开头的发布，只接受本仓库发布页的 APK；发现新版本先问你，再用系统下载器下载，下载好打开系统安装界面，由你点「安装」。第一次需要允许「安装未知应用」。必须和已装版本同一个固定签名才能覆盖安装（0.3-preview 起都是固定签名）。这是应用唯一联网的地方。

没有画「摸摸头」的宠物（煤球猫猫、百变猫猫五只、99狐狐、沙漠狐、灰鸮g老师），点一下改播「害羞」。应用图标改用千千猫猫的托盘图标（通知栏小图标仍是单色的 `ic_pet`，系统要求单色）。
