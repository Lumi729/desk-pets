# 梨间雪桌宠 · 美化包格式（v1）

一个美化包 = 一个 .zip，根目录里放：

- `theme.json`（必须）
- `island_left.png` / `island_middle.png` / `island_right.png`（必须）：灵动岛三段像素图，三张同样高度；左右两段不拉伸，中间段横向平铺。像素图，必须用最近邻缩放。
- 可选：`icons/` 里放同名图标覆盖默认面板图标（prev、play、pause、next、timer、hide、move、close、heart，PNG，11×11 像素格）。没放的用默认图标并按 `colors.icon` 着色。

## theme.json

```json
{
  "id": "lili-bunny",            // 唯一 id，只允许小写字母、数字、- 
  "name": "梨梨兔兔",             // 下拉框里显示的名字
  "version": 1,                   // 格式版本，目前只认 1
  "mascot": "梨梨兔兔",           // 坐在面板顶上的宠物名；不存在就用当前第一只显示的宠物
  "colors": {
    "background": "#F6F3F4",      // 设置页背景
    "panel": "#FFFFFF",           // 面板 / 按钮底色
    "rim": "#555458",             // 像素描边
    "card": "#F1ECEE",            // 面板里的卡片
    "accent": "#E8A0B8",          // 主按钮、进度条、开关打开
    "accentText": "#FFFFFF",      // 主按钮上的文字和图标
    "text": "#2C2C2A",            // 面板里的主要文字
    "subtext": "#8D868B",         // 次要文字、箭头
    "pageText": "#2C2C2A",        // 设置页标题和正文
    "pageSubtext": "#8D868B",     // 设置页说明文字
    "track": "#DCD5D8",           // 进度条底、开关关闭
    "icon": "#2C2C2A",            // 默认图标着色
    "patch": "#2C2C2A"            // 可选：面板角落的装饰色块（梨梨兔兔的黑色花斑）；不写就不画
  }
}
```

## 安全规则

- 只接受 .zip；解压时只取上面列出的文件名，其他文件忽略；禁止路径里出现 `..` 或绝对路径。
- 单张图片不超过 512 KB，整个包不超过 2 MB；PNG 解码失败就拒绝导入并提示原因。
- 颜色必须是 `#RRGGBB` 或 `#AARRGGBB`，缺的颜色用默认主题补上。
- 美化包里不能有、也不会执行任何代码，只换颜色和图片。
