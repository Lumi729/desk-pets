# 安卓倾斜爬边与探头 · 给小克的补画清单

2026-10-08 · Codex（g老师）根据千千的需求整理。

状态：设计与素材核对完成，攀爬功能尚未实现，不包含在 Android 0.12-preview。请先补动画，再接手机端状态切换与传感器触发。现有「摇晃」「吐彩虹」「灵动岛」不能代替侧边攀爬动画。

## 想要的效果

手机向左倾斜，伙伴走到左边，沿左侧边向上爬；向右倾斜就走右边。到屏幕上半部分后藏到边缘外，主要露出脑袋和一点爪子，眨眼、看人。屏幕中间空出来，避免挡住阅读。

建议的交互：倾斜保持一小会儿才触发，避免手抖；爬到上半部分就安静探头，手机摆正不立即掉下来。拖出来或双击可以退出，再沿用原来的掉落、落地动画。与摇晃、摸摸、剧情协调，不能互相抢动作。新开关默认关闭，熄屏或收起时停止传感器与动画。具体阈值和露头比例在真机试用后微调。

## 必须补画：每套角色 4 个 GIF

| 文件名 | 动作 | 画面方向 |
| --- | --- | --- |
| 沿左边向上爬.gif | 手脚交替抓住竖直边缘向上爬，可无缝循环 | 抓点在中央竖线，身体在画面右半侧 |
| 沿右边向上爬.gif | 同上，沿右边爬 | 抓点在中央竖线，身体在画面左半侧 |
| 左边探头.gif | 身体藏在左边，只把头和一点爪子伸向屏幕里面；眨眼、耳朵动，可循环 | 身体在中央线左边，头和爪子伸向右边 |
| 右边探头.gif | 身体藏在右边，向屏幕里面探头 | 身体在中央线右边，头和爪子伸向左边 |

「左/右」指手机屏幕的左/右边，不是角色自己的左/右手。探头时身体应处于边缘外，不是整只站在屏幕里面。

## 可选加分：每套角色 2 个过渡 GIF

- `左边藏起来.gif`：从左侧爬行最后一帧接过去，侧身缩到边外，最后接「左边探头」第一帧。
- `右边藏起来.gif`：对应右侧。

这两个不是第一版必需；没有时可以由程序平滑移动、切换。先把 4 个必要动作做好。不需要另画掉落、摔趴趴、普通走路。

## 素材规范

- 透明背景 GIF，画布 **300×250**，与仓库当前单只角色动作一致；保留现有角色比例、像素风、配色和配饰。
- 中央竖线 **x=150** 是屏幕边缘的对齐参考，不要把这条线或手机边框画进成品。
- 每帧画布、锚点保持固定。爬行 GIF 在原位交替动手脚，整只向上移动交给程序，不能让角色在 GIF 内一路漂出画布。
- 爬行可先做 4–8 帧循环；探头可做 8 帧左右，停留多一点，偶尔眨眼。现有常见帧间隔约 260ms，可按动作自然程度调整，不能闪烁。
- 左右动作可用镜像作为草稿，但眼镜、耳饰、发型、衣服等不对称细节须校正，不能一键镜像后不检查。
- 不画整屏背景、阴影底板、文字或边框；只有宠物像素和透明区域。
- 程序接入时按中央边缘线裁掉屏幕外的身体，只给露出的头和爪子保留小触摸区域，不用整屏透明窗口挡操作。

## 给后续接代码的人

- 倾斜数据已由 `ShakeCompanion.tilt` 提供，已按屏幕旋转映射；目前只用于摇晃弹力球的横向运动。
- 新动作还未加入 `android/scripts/prepare-assets.cjs` 的打包列表，接功能时一并加入并验证文件存在。
- `PetService.position()` 当前把宠物窗口限制在屏幕内，不能仅把 x 改成负数就当作身体已经藏好；需要实现小窗口内的画布平移与裁剪，避免系统自动把窗口推回屏幕。
- 攀爬、藏入、探头应有独立状态，触摸、旋转、收起、摇晃和其它剧情可正确退出；隐藏后不保留屏幕中间的透明触摸框。
- 传感器倾斜触发、横竖屏、左右边缘对齐与不同手机实际窗口裁剪都需要真机验证。
